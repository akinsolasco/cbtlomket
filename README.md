# Lomket CBT 1.0.1

Lomket CBT is a local-network computer-based testing app. The admin runs as a desktop app on one computer. That same computer quietly acts as the server for students, who open unique exam links in a normal browser on the same Wi-Fi/LAN.

## Install

Use the Windows installer generated in `dist`:

```text
dist\Lomket-CBT-Setup-1.0.1.exe
```

Install it on the admin computer, then open **Lomket CBT Admin** from the desktop shortcut or Start Menu. The admin desktop app starts the student web server automatically.

First login is `admin` / `Lomket@2026`. Change it in Settings before a real exam.

## Developer Start

If you are working from source before building the installer:

```powershell
npm install
npm run desktop
```

For troubleshooting only, `Start-Lomket-CBT-Server-Only.cmd` starts just the student web server without the desktop admin window.

## Student Access

Create students, build an exam set, create an assignment, then click `Push live`. The admin console shows a unique `/exam/...` link. Students must be on the same network and sign in with:

```text
firstname@StudentID
```

Example: Ada with user ID `LOM001` uses `ada@LOM001`.

Students should not use the admin computer's home page. They must use the exact exam link generated by the desktop admin app.

## Data Storage

All records are saved locally in:

```text
data/lomket-db.json
```

Back up this file before moving computers or applying major updates.

## Features

- Admin splash screen and secure admin login.
- Desktop admin application that starts the local server.
- Local students list with generated temporary passwords.
- Exam sets with multiple-choice, typed, theory, and practical questions.
- Question pool with ready-made samples for Word, Excel, PowerPoint, computer basics, email/internet safety, and Python.
- Live assignments with unique access links and student restrictions.
- "No active exam now" message when a link is not live.
- Automatic marking for multiple-choice and accepted typed answers.
- Manual marking for theory, practical, and typed questions without accepted answers.
- Optional immediate score display.
- Results table and CSV export.
- LAN link discovery for the admin computer.
- Student-only browser landing page for non-exam web visits.
- GitHub release update checker and update download location.
- Desktop auto-update from GitHub Releases.
- Owner-only password reset script.

## Build Installer

```powershell
npm install
npm run dist
```

The installer appears in `dist`. To publish an update, increase the version in `package.json`, then run:

```powershell
$env:GH_TOKEN="your_github_token"
npm run release
```

The release upload must include the generated `.exe`, `.blockmap`, and `latest.yml`. Installed copies of Lomket CBT check GitHub Releases automatically on startup and every 6 hours while the app is open.

This repository also includes `.github/workflows/release.yml`. After the code is pushed to GitHub, create a tag such as `v1.0.1`; GitHub Actions will build the Windows installer and publish the release files needed by auto-update.

## Password Reset

If the admin password is lost, run this on the admin computer:

```powershell
node scripts\reset-admin-password.js NewStrongPassword
```

Then restart the server and sign in with the new password.

## Test

```powershell
node scripts\smoke-test.js
```

The smoke test verifies admin login, assignment creation, student login, submission, and manual marking.
